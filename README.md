🌐 **Site:** https://glasneau.github.io/dona-do-doce/
📸 **Instagram:** [@adonadodoce_](https://www.instagram.com/adonadodoce_/)
🛵 **Delivery:** [Yooga](https://delivery.yooga.app/dona-do-doce/tabs/home) · [DeliveryOn](https://web.deliveryon.com.br/cardapio/donadodoce)

## Como editar

Site estático em HTML, CSS e JavaScript, sem instalação nem build.

| O que mudar | Arquivo |
|---|---|
| Links, WhatsApp, endereço, avaliação | `assets/js/config.js` |
| Produtos, preços e fotos do cardápio | `assets/js/menu.js` |
| Horário de funcionamento | `assets/js/store-hours.js` |
| Fotos | `assets/img/` (veja `LEIA-ME.txt`) |

Para testar as regras de horário: `npm test` (requer Node.js).
